# 地層シミュレーター（6年 理科「大地のつくりと変化」）

水のはたらきでできた地層が、どのようにしてできたのかを体験するWebアプリです。
インストール不要。ChromebookやiPad、PCのブラウザで動きます。

**公開URL**: https://johnnymaeta.github.io/chiso-simulator/

## 画面

| タブ | 内容 | 教科書との対応（6年理科） |
|---|---|---|
| ① 実験：ペットボトルに流しこむ | 砂やどろをふくむ土を水といっしょに注ぎ、しずんで層になるようすを観察する。2回目を注ぐと層がくり返される | 実験2「砂やどろなどが、水中でどのようにたい積するか調べる」・結果 |
| ② 川から海へ | 大雨で山がけずられ（しん食）、川が土を運び（運ぱん）、海の底に積もる（たい積）。河口に近いほど大きなつぶ、遠いほど小さなつぶが積もる。海の底をタップすると柱状図が見られる | p.131 考察の図（しん食・運ぱん・たい積）・わかったこと |
| ③ まとめ・たしかめ | わかったこと、つぶの大きさ（れき・砂・どろ）、れき岩・砂岩・でい岩、たしかめ問題6問 | p.131〜132・p.123（つぶの大きさ） |

## 授業での使いどころ

- 第4時（予想）: ②で「川が運んだ土が海の底に積もる」イメージをもたせる
- 第5時（実験）: 実際のペットボトル実験の前後に①で確かめる。沈殿を待つ間の見本にも使える
- 第7時（まとめ）: ③のたしかめ問題で確認

## 技術

- 単一の `index.html`（HTML + CSS + JavaScript、外部ライブラリなし）
- GitHub Pages で公開（`main` ブランチのルート）

## 注意

- シミュレーションは教科書の実験の流れと結果（つぶの大きさごとに分かれて積もる・くり返すと層が重なる）を再現するもので、実際のしずむ速さや層の厚さを正確に計算したものではありません。
